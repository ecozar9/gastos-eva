# Mis finanzas — versión con ingresos

Esta versión permite añadir gastos e ingresos, ver el saldo mensual y descargar el resumen para Excel.

## Actualizar GitHub

1. Descomprime el ZIP.
2. En tu repositorio, pulsa `Add file > Upload files`.
3. Sube y sustituye `index.html`, `style.css`, `app.js`, `manifest.webmanifest` y `service-worker.js`.
4. La carpeta `icons` solo es necesaria si todavía no estaba subida.
5. Pulsa `Commit changes`.

## Después de actualizar

Abre la web en Safari, recarga la página y vuelve a abrir el icono instalado. Si tarda en cambiar, cierra completamente la app y Safari y vuelve a entrar.

## Datos anteriores

La aplicación intenta recuperar automáticamente los gastos guardados por la versión anterior y los clasifica como gastos.
